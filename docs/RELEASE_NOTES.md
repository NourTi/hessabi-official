# Hessabi v0.1.0 — First official preview

Hessabi is an offline-first billing and stock companion for Algerian traders, shop sellers, boutiques, and small wholesalers. This preview release focuses on practical daily selling: product entry, DZD prices, receipts, local stock, payment-method recording, and Arabic/Darija-first onboarding.

## Before installing

This is a **debug preview APK**, not a Play Store production build. Android may ask you to allow installation from your browser or file manager. Test it on your own device before using it for live customer transactions.

Hessabi records Cash, CIB, and EDAHABIA as payment methods on a receipt. It does **not** process bank or card transactions. Bluetooth printing and camera barcode scanning must be verified against your device and hardware.

## Installation

1. Download the Android APK.
2. Open the file from Android Downloads or Files.
3. Allow installation from that source if Android requests it.
4. Open Hessabi, select Darija, Arabic, or French, and enter your shop name.
5. Add a product, complete a test sale, and confirm that the receipt and stock update are correct.

The application data is stored locally on the device. Export a backup regularly and do not assume that deleting or resetting the phone preserves your sales data.
